L12_C1–L12_C8 CHEMISTRY PRACTICE SITE
SOURCE CODE AND SETUP INSTRUCTIONS
==================================

RECOMMENDED PAGE
----------------
- index1.html: the corrected practice page with seven corrected question entries.
- index.html: redirects visitors to index1.html on the published website.
- README.md: project overview and live links.

RUN THE SITE
------------
Open the live site at:
https://pete-rvu.github.io/l12-chemistry-practice/

To open the corrected page directly, use:
https://pete-rvu.github.io/l12-chemistry-practice/index1.html

For local use, open index1.html in a current version of Chrome, Edge, or Firefox.
Choose a chapter card to study one chapter at a time; L12_C1 through L12_C8
remain separate.

Before starting, choose 10, 20, 40, or all questions and choose when to check
answers: after each question or after submitting the set. New questions and
questions answered incorrectly are prioritized in later sets. The clock starts
at 00:00 and counts upward with no time limit.

The question bank is embedded in each HTML file. No separate data files,
external JavaScript packages, or build tools are needed.

GITHUB PAGES AND PUBLIC ACCESS
------------------------------
The public repository is:
https://github.com/Pete-rVu/l12-chemistry-practice

GitHub Pages serves the public website from the main branch and root folder.
The root index.html redirects to the recommended index1.html page.

The repository and site are public. The HTML files contain the questions and
answer keys, which anyone can view or download. Quiz results are calculated in
the browser and are not sent to a server. Browser storage is used, when
available, to prioritize new and previously missed questions.
